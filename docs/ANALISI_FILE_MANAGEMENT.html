1. Introduzione & Richiesta

📌 Obiettivo

Aggiungere per admin/superadmin un sistema di gestione file (PDF, immagini, documenti) con:

  • Upload/download file
  • Ricerca file
  • Gestione cartelle e sottocartelle
  • Storage cloud gratuito (minimo 10GB)
📍 Vincoli Tecnici:
  • File NON memorizzati in Supabase Database
  • Storage esterno in cloud
  • Minimo 10GB gratuito permanente
  • Integrazione con architettura Fortitudo

2. Analisi Storage Cloud Gratuito

Opzioni Valutate

A) Google Drive (15GB Gratis)

Caratteristiche

  • Storage: 15GB (condiviso con Gmail/Photos)
  • Upload rate: 10GB/giorno
  • API calls: 1 miliardo/giorno (illimitato)
  • Rate limiting: 100-200 req/min

✅ Vantaggi

  • Interfaccia familiare (Google Drive app)
  • 15GB gratuito permanente
  • Cartelle/sottocartelle native
  • Condivisione file via link
  • Preview PDF/immagini integrato
  • Backup automatico
  • Sync desktop (Google Drive app)

❌ Svantaggi

  • Setup OAuth complesso (~1h)
  • Rate limiting strict (bottleneck potenziale)
  • API latenza non ottimale
  • No versioning file
  • Dipendenza Google (ToS possono cambiare)

💰 Costi: Gratis fino a 15GB. Oltre: $1.99/100GB (Google One)

🕐 Effort implementazione: 11.5 ore

B) Dropbox (2GB Gratis)

Caratteristiche

  • Storage: 2GB
  • File size max: 350GB singolo file
  • Rate limiting: 500 req/s (generoso)

✅ Vantaggi

  • API pulita e ben documentata
  • Versioning file nativo
  • Sharing link con scadenza
  • SDK semplice
  • Rate limiting generoso
  • Sync desktop integrato

❌ Svantaggi

  • ❌ Storage insufficiente: Solo 2GB
  • Upgrade costoso: $99.99/anno per 2TB
  • No cartelle condivise native
  • Vendor lock-in

💰 Costi: Gratis 2GB (insufficiente). Dropbox Plus $99.99/anno

🕐 Effort implementazione: 9 ore

C) Microsoft OneDrive (5GB Gratis)

Caratteristiche

❌ Svantaggi

  • ❌ Storage insufficiente: Solo 5GB
  • API complessa (Microsoft Graph)
  • Setup OAuth (simile a Google)
  • Upgrade: Microsoft 365 $69.99/anno

💰 Costi: Gratis 5GB (insufficiente). Microsoft 365 $69.99/anno

Vantaggi:

  • ✅ Zero costi upgrade per 5+ anni

  • ✅ Spazio abbondante (Google 15GB + Supabase ∞)

  • ✅ Splitting intelligente per size file

🕐 Setup: 28.5 ore (Supabase 17h + Google Drive 11.5h)

💰 Costi 5 anni: $0 (gratis permanente)

Database Schema (Opzione Ibrida)

CREATE TABLE admin_file_sync_configs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  provider TEXT NOT NULL CHECK (provider IN ('google_drive', 'supabase')),
  user_id UUID NOT NULL REFERENCES profiles(id),
  access_token TEXT,
  refresh_token TEXT,
  root_folder_id TEXT,
  last_sync_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE admin_files (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  folder_id UUID REFERENCES admin_folders(id),
  filename TEXT NOT NULL,
  mime_type TEXT,
  size_bytes BIGINT,
  provider TEXT NOT NULL,  -- 'supabase' o 'google_drive'
  storage_path TEXT UNIQUE,
  external_id TEXT,  -- Google Drive file ID
  uploaded_by UUID NOT NULL REFERENCES profiles(id),
  uploaded_at TIMESTAMPTZ DEFAULT now(),
  tags TEXT[] DEFAULT '{}',
  UNIQUE(folder_id, filename)
);

CREATE TABLE admin_folders (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  parent_id UUID REFERENCES admin_folders(id),
  created_by UUID NOT NULL REFERENCES profiles(id),
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE admin_file_audit (
  id BIGSERIAL PRIMARY KEY,
  file_id UUID REFERENCES admin_files(id),
  action TEXT CHECK (action IN ('upload', 'download', 'delete', 'move')),
  actor_id UUID REFERENCES profiles(id),
  occurred_at TIMESTAMPTZ DEFAULT now()
);

7. Raccomandazione Finale

✅ OPZIONE CONSIGLIATA: Supabase + Google Drive (Ibrida)

Perché questa combinazione?

  • Zero costi: Gratis permanente (15GB Google + ∞ Supabase)
  • Performance ottima: File piccoli in Supabase (veloce), file grandi in Google Drive
  • Spazio abbondante: 15GB + ilimitato = più che sufficiente
  • Integrazione: Metadata centralizzato in DB Supabase
  • Ridondanza: Backup automatico in due provider
  • Familiarità: Google Drive interfaccia nota agli utenti

Effort totale: 28.5 ore
